# Event Manager – Система организации корпоративных мероприятий

Веб-приложение на Django для учёта корпоративных мероприятий и регистрации сотрудников на них.

## Назначение
Приложение позволяет планировать мероприятия, регистрировать сотрудников, контролировать места и просматривать информацию через веб-интерфейс.

## Целевая аудитория
- HR-специалисты и организаторы мероприятий;
- Сотрудники компании, регистрирующиеся на мероприятия.

## Предметная область
Компания проводит корпоративные мероприятия (тимбилдинги, конференции, семинары). У каждого мероприятия есть дата и ограниченное число мест. Сотрудники регистрируются на мероприятия, регистрацию можно отменить.

## Основные сущности
- **Мероприятие (Event)**: идентификатор, название, дата, вместимость.
- **Регистрация (Registration)**: идентификатор, ссылка на мероприятие, имя сотрудника, статус.

## Используемые технологии
- Python 3.10+
- Django 5.2.*
- Bootstrap 5.3 (через CDN)
- pytest, flake8
