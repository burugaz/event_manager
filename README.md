# Система организации корпоративных мероприятий

Консольное приложение для учёта корпоративных мероприятий
и регистрации сотрудников на них.

## Назначение
Приложение для организации корпоративных мероприятий компании:
планирование мероприятий, регистрация сотрудников, контроль мест.

## Целевая аудитория
- HR-специалисты и организаторы мероприятий;
- сотрудники компании, регистрирующиеся на мероприятия.

## Предметная область
Компания проводит корпоративные мероприятия (тимбилдинги, конференции,
семинары). У каждого мероприятия есть дата и ограниченное число мест.
Сотрудники регистрируются на мероприятия, регистрацию можно отменить.

## Основные сущности
- мероприятие;
- сотрудник;
- программа мероприятия;
- регистрация сотрудника на мероприятие.

На текущем этапе (ПР2) данные хранятся в словарях и списках:
мероприятия и регистрации. Сотрудник пока представлен именем
в регистрации, программа мероприятия будет добавлена на следующих этапах.

## Возможности
- просмотр мероприятий (по дате) с заполненностью;
- поиск мероприятия по названию;
- проверка вместимости и подбор мероприятий по вместимости;
- проверка возможности регистрации (дата и свободные места);
- регистрация сотрудника на мероприятие;
- отмена регистрации;
- просмотр регистраций;
- добавление мероприятий;
- сохранение данных между запусками в JSON-файлах.

## Правила регистрации
- нельзя зарегистрироваться на прошедшее мероприятие;
- нельзя зарегистрироваться, если свободных мест нет;
- сотрудник не может зарегистрироваться на одно мероприятие дважды.

## Структура проекта
- main.py — точка запуска и меню;
- events.py — работа с мероприятиями;
- registrations.py — работа с регистрациями;
- storage.py — загрузка и сохранение данных (JSON);
- utils.py — безопасный ввод чисел и дат;
- data/ — JSON-файлы данных (events.json, registrations.json);
- tests/ — автоматизированные тесты (pytest).

## Формат данных
`data/events.json` — список мероприятий:

```json
{"id": 1, "title": "Осенний тимбилдинг", "date": "2026-12-12", "capacity": 50}
```

`data/registrations.json` — список регистраций:

```json
{"id": 1, "event_id": 1, "employee": "Иван Петров"}
```

## Требования
- Python 3.10 или новее;
- pytest;
- flake8.
