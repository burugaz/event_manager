# Система организации корпоративных мероприятий

## Назначение
Приложение для организации корпоративных мероприятий компании:
планирование мероприятий, программа, регистрация сотрудников.

## Целевая аудитория
- HR-специалисты и организаторы мероприятий;
- сотрудники компании, регистрирующиеся на мероприятия.

## Предметная область
Компания регулярно проводит корпоративные мероприятия (тимбилдинги,
конференции, обучающие семинары). У каждого мероприятия есть дата,
ограниченное число мест и программа. Сотрудники регистрируются
на мероприятия, регистрацию можно отменить.

## Основные сущности
- мероприятие;
- сотрудник;
- программа мероприятия;
- регистрация сотрудника на мероприятие.

## Основные функции
- расчёт количества свободных мест на мероприятии;
- расчёт процента заполненности мероприятия;
- проверка, что мероприятие ещё не прошло;
- определение статуса регистрации на мероприятие.

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
